# Cyphermita

#### By Guillermo Torre Perez, Braylen Milstead, and  Alec Tholkes.

This will be a guide on how to participate and learn new cyber skills so that people who want to start learning about cybersecurity can follow this guide to eventually get a job in the industry.​  This will be shown using different resources, guiding users through a step-by-step process of things to look for and common answers to CTF problems.​
