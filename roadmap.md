## 🎯 Learning objectives

By the end of this stage, you should be able to:

- Understand hardware components and how data moves through a system.
- Differentiate between Windows and Linux architectures and filesystems.
- Master essential command-line navigation and file management.
- Set up and configure virtual machines safely.

## 1. Hardware and software fundamentals

Before you can secure or break a system, you must understand its anatomy.

### CPU and memory (RAM)

The processor executes instructions fetched from volatile memory. Security concepts like buffer overflows depend on how memory stacks and heaps are managed.

### Storage (HDD vs. SSD)

Non-volatile storage is where operating systems, files, and logs live. It is critical for digital forensics and data recovery.

### Kernel vs. user space

The kernel is the core boundary in modern operating systems. The kernel has unrestricted access to hardware, while user applications run in an isolated space with restricted privileges.
